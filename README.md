# Peptide Dosage Demo — Static Site (GitHub Pages)

A static peptide reference site with a client-side reconstitution calculator,
hosted on **GitHub Pages**.

> Demo/educational content only. Dosing figures are illustrative; not medical guidance.

## Files

Flat HTML — no build step, no server. `index.html`, `single-peptides.html`,
`blends.html`, `calculator.html`, `protocol-*.html`, plus `styles.css` and
`app.js` (client-side calculator).

## Deploy

Push to `main` on `https://github.com/MikeShermetaro/peptide-site`, then:

1. Repo → **Settings → Pages**
2. **Source:** Deploy from a branch
3. **Branch:** `main`, folder **/ (root)** → **Save**
4. Wait ~1 minute. The site is live at
   `https://mikeshermetaro.github.io/peptide-site/`
